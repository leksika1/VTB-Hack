# Тестовые данные v2

`POST /api/demo` создаёт изолированную копию на 24 часа. Маршрут временный: после перехода фронта на
локальное демо он будет удалён. Постоянная витрина создаётся командой:

```powershell
cd backend
.venv/Scripts/python.exe -m app.seed --reset
```

## Состав

| Имя | Статус | Примечание |
|---|---|---|
| Петя | active | владелец, тестовый ВТБ ID `petya` |
| Маша | active | участник, тестовый ВТБ ID `masha` |
| Нина | active | участник; тестовый логин `sonya` теперь ведёт к обычному участнику |
| Даша | pending | видна всем, решение доступно только Пете |

У каждого есть личный loginId; он генерируется при пересоздании и доступен только в его `GET /api/me`.
Имена не уникальны — отдельного участника определяет ID.

## Наполнение

- бюджеты текущего и прошлого месяца;
- общие и разделённые покупки на троих, личная покупка из импорта;
- пополнения общего счёта;
- ЖКУ: автоплатёж по счёту с лимитом;
- интернет: ежемесячный автоплатёж по дате;
- детский сад: ручной платёж по УИН;
- ОСАГО: ручной платёж по банковским реквизитам;
- годовая подписка по карте;
- общая цель со взносами.

Даты считаются относительно дня создания. Перед показом витрину стоит пересоздать `--reset`.

Файлы для импорта и QR: `docs/samples/statement.csv` и `docs/samples/receipts.txt`.
