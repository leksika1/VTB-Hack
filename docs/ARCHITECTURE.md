# Архитектура v2

## Слои

```
frontend (React) → FastAPI api → services → domain → PostgreSQL
                              ↘ Redis (rate limits, OIDC, realtime)
```

API отвечает за HTTP-контракт и зависимости авторизации; services — транзакции и проверку прав;
domain — чистые денежные расчёты. Все суммы в БД — `BIGINT` в копейках. Alembic — единственный
источник схемы. После успешной записи middleware публикует семейное SSE-событие `changed`.

## Доступ

`families.owner_id` указывает единственного владельца. Все активные `members` могут вести бюджет;
только владелец меняет состав семьи. Ожидающий или отклонённый участник авторизован в изолированном
режиме: получает только название семьи, свой профиль, статус и личные уведомления. Сессии и loginId
ищутся по SHA-256; ВТБ ID остаётся независимым OIDC sub.

## Денежная модель

Расход хранит источник, режим деления, выбранных участников и доли в базисных пунктах. Старый
`account_mode` пока дублируется для совместимости. Сводка общего счёта вычисляется сервером из
пополнений и расходов на дату; персональная задолженность — из долей, взносов и личной оплаты.

Платёж хранит сумму/режим суммы, правило серии, способ оплаты и реквизиты. Уникальность
`(series_id, due_date)` и `INSERT ... ON CONFLICT DO NOTHING` защищают серии от дублей. Оплата блокирует
семью и строку платежа, проверяет остаток, создаёт расход и следующее вхождение в одной транзакции.
Фоновый автоплатёж выбирает строки через `FOR UPDATE SKIP LOCKED`, поэтому безопасен для двух реплик.

## Отчёты

`services/account.py` — единый расчёт общего счёта и долей. Analytics и Calendar переиспользуют его:
для прошлого восстанавливают баланс по операциям, для будущего вычитают неоплаченные платежи.
Прогнозы в v2-аналитику не входят; старый forecast-маршрут сохранён только для совместимости.

## Масштабирование

Backend stateless: токены сессий хешированы в PostgreSQL, краткоживущее состояние и pub/sub — в Redis.
Идемпотентность записей хранится в БД. Несколько реплик безопасно обрабатывают повторы, серии и автоплатежи.
